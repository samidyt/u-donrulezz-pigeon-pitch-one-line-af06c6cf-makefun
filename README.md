## Entry

One-line elevator pitch a city pigeon gives investors for its startup:

> I'm not asking for seed funding — I'm asking for seed. Literal birdseed. $2M turns every statue downtown into a billboard, and every crumb into a dividend.

## How it works

`main.ts` writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and prints it to stdout. It refuses to write a line that is empty, multi-line, or over 200 characters.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
